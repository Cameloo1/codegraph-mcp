# Nuance Rescue Matrix Fixture

Deterministic adversarial fixture for binary/1-bit nuance-loss work.

This fixture is intentionally small. It is meant to prove candidate-recall
behavior around exact seeds, binary Hamming loss, and 1-bit nuance rescue. It
does not define graph proof expectations beyond the explicit manifest contract:
vector, binary, and nuance-rescue candidates remain non-proof until graph/source
verification succeeds.

Primary manifest:

`manifest.json`

Fixture families:

- rare identifier
- short function
- near-duplicate names
- Buildroot config
- auth/role/negation
- route literal
- test name
- no-extension support script
