# MVP3 Validation Fixtures

Durable MVP3.8 fixture manifests live here. Generated repos, DBs, logs, and
runner output belong under `reports/audit/artifacts/mvp3_validation_fixtures/`
or `target/`, not in this directory.

These initial fixtures are harness samples only. They prove the manifest schema,
runner loop, command planning, and structured assertion engine before the full
MVP3 validation fixture matrix is added.
