# README terminal sequence

The promoted README command sequence is now a deterministic SVG generated by
the shared brand asset tool. It is intentionally illustrative rather than a
captured shell session, which avoids stale machine-local paths and keeps the
visual system reproducible.

Generate all promoted README SVGs from the repository root:

```bash
python scripts/brand/generate_proof_field.py --all
```

The terminal preset renders current agent-use command shapes from
`scripts/brand/proof_field_presets.json` into
`docs/assets/readme/codegraph_terminal.svg`.

Review the promoted SVG for:

- current command syntax;
- no machine-local paths;
- no secrets;
- no unsupported performance or external-score claims;
- no normal `.codegraph` mutation;
- an accessible SVG title and description.

An asciinema recording may still be produced for release media when useful,
but it should remain under ignored audit paths until reviewed. The deterministic
SVG is the public README source of truth.
